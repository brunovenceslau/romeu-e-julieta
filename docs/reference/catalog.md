# Egress catalog

The format `catalog.v1` of `internal/catalog/egress/*.yaml`, one file per tool family,
embedded in romeu and julieta ([03 3.5](../spec/03-formats.md#35-egress-catalog-internalcatalogegressyaml-schema-catalogv1)).
A file is written by the maintainer, so its reader refuses an unknown key (ADR 0041). The
`meta` and `base` sets live in `base.yaml` alone. A domain or a tool that two files declare
with different entries is a decode error, and `tools/ci catalog` refuses a domain used
anywhere without an `upload` entry.

Its JSON Schema is [schemas/catalog.v1.json](../../schemas/catalog.v1.json).

## Fields

| Field | Type | Required | Meaning |
|---|---|---|---|
| `schema` | string | yes | Schema is "catalog/v1". |
| `meta` | list of string | no | Meta are the domains of mise itself, needed by every project; only base.yaml holds them. |
| `base` | list of string | no | Base are the domains of git over HTTPS, needed by every project; only base.yaml holds them. |
| `domains` | map of string to object | no | Domains holds the upload flag of each domain; CI refuses a domain used anywhere without an entry here. |
| `domains{}.upload` | boolean | yes | Upload says that data can be sent out to the domain, as to a multi-tenant object store; such a domain is always gated. |
| `tools` | map of string to list of string | no | Tools maps a mise backend:tool, as written in mise.lock, to the domains it needs to install and to run. |
