# Host settings

The format `host-settings.v1` of `settings.yaml`, which romeu reads on the host
([03 3.4](../spec/03-formats.md#34-host-settings-settingsyaml-schema-host-settingsv1)).
`romeu init` writes `root`, `config` and `tools`; the operator fills the rest.

Its JSON Schema is [schemas/host-settings.v1.json](../../schemas/host-settings.v1.json).
