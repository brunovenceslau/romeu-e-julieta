# julieta install

install the locked tools of every repo with mise

### Synopsis

Runs mise install, locked, in every repo of the manifest that has a mise.toml, or in the repo --repo names. It does nothing when the lock-set digest of the mise.lock files equals the last success; --force installs anyway. A repo with a mise.toml and no mise.lock is the error lock-missing, and a download the egress policy blocks is install-blocked.

```
julieta install [flags]
```

### Examples

```
julieta install
julieta install --repo api
julieta install --force
```

### Options

```
      --force         install although the lock-set digest equals the last success
  -h, --help          help for install
      --repo string   the dir of the one repo to install, as the manifest names it
```

### Side effects

- **P** (preflight): no
- Lock: no
- Appends on each run: nothing
- Writes a julieta snapshot: no
- Idempotency: a second run with no input change leaves files and refs as they were

### Exit codes

| Exit | Meaning |
|---|---|
| 0 | ok |
| 1 | the operation failed |
| 2 | usage or precondition |
| 3 | approval required |
| 4 | drift detected, or an interrupted promotion abandoned |
| 5 | refused to protect data |
| 6 | the check ran and found what it checks for |
| 130 | ended by SIGINT |
| 143 | ended by SIGTERM |

A signal wins over a failure the command had already found (1 to 6); a command that had finished its work keeps 0.
