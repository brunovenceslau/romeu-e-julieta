# julieta salvage

capture every repo's unpushed work into its memory dir before the sandbox goes

### Synopsis

Runs the sandbox half of a salvage for the salvageRun id of the manifest: with --stop-agents, it stops the agent's processes and waits on every store lock first; then, for each repo of the manifest and each nested repository in its worktrees, it records each worktree's uncommitted changes and each stash under refs/salvage/<generation>/<salvage-id>/, writes one bundle per repository, archives the ignored files and the agent's state within salvage.capBytes, and writes manifest.json last in memory/<dir>/salvage/<generation>/<salvage-id>/. Transcripts are kept only with --include-transcripts. With --fingerprint it prints the fingerprint object of the same reads and writes nothing.

```
julieta salvage [flags]
```

### Examples

```
julieta salvage --stop-agents --json
julieta salvage --fingerprint
```

### Options

```
      --fingerprint           print the fingerprint object and write nothing
  -h, --help                  help for salvage
      --include-transcripts   keep the agent's transcripts, which may hold echoed tokens
      --json                  print one JSON document
      --stop-agents           stop the agent's processes and wait on the store locks first
```

### Side effects

- **P** (preflight): no
- Lock: no
- Appends on each run: a salvage dir per repo and the refs of the salvage id
- Writes a julieta snapshot: no
- Idempotency: each run adds one thing

### Exit codes

| Exit | Meaning |
|---|---|
| 0 | ok |
| 1 | the operation failed |
| 2 | usage or precondition |
| 3 | approval required |
| 4 | drift detected, or an interrupted promotion abandoned |
| 5 | refused to protect data |
| 6 | the check ran and found what it checks for |
| 130 | ended by SIGINT |
| 143 | ended by SIGTERM |

A signal wins over a failure the command had already found (1 to 6); a command that had finished its work keeps 0.
