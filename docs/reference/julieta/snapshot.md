# julieta snapshot

bundle the unpushed work of a repo into its memory dir's snapshot/

### Synopsis

Writes snapshot/heads.bundle, then snapshot/heads.json, in the memory dir of the repo of the working directory, of --repo, or of every repo of the manifest with --all. The bundle holds the local branches, tags and notes, the current generation's refs/salvage/ refs, each detached worktree HEAD and each reflog commit no other ref reaches, minus the objects the manifest's base reaches; heads.json lists every ref read. The snapshot of a repo waits for the store lock of its memory dir. The hook dispatcher takes the same snapshot after post-commit, post-rewrite and post-merge.

```
julieta snapshot [flags]
```

### Examples

```
julieta snapshot
julieta snapshot --repo api
julieta snapshot --all
```

### Options

```
      --all           snapshot every repo of the manifest
  -h, --help          help for snapshot
      --repo string   the repo dir to snapshot, instead of the repo of the working directory
```

### Side effects

- **P** (preflight): no
- Lock: no
- Appends on each run: a rewritten snapshot/heads.json, whose createdAt moves
- Writes a julieta snapshot: yes
- Idempotency: each run adds one thing

### Exit codes

| Exit | Meaning |
|---|---|
| 0 | ok |
| 1 | the operation failed |
| 2 | usage or precondition |
| 3 | approval required |
| 4 | drift detected, or an interrupted promotion abandoned |
| 5 | refused to protect data |
| 6 | the check ran and found what it checks for |
| 130 | ended by SIGINT |
| 143 | ended by SIGTERM |

A signal wins over a failure the command had already found (1 to 6); a command that had finished its work keeps 0.
