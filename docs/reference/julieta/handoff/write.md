# julieta handoff write

write a handoff of the session to the repo's memory dir

```
julieta handoff write [flags]
```

### Examples

```
julieta handoff write < handoff.md
julieta handoff write --final < handoff.md
julieta handoff write --facts
```

### Options

```
      --facts         write a facts handoff, with no narrative (the SessionEnd hook)
      --final         write a final handoff, before recreate or rm; it needs a sixth heading
  -h, --help          help for write
      --json          print one JSON document
      --repo string   the repo dir to file under, instead of the repo of the working directory
```

### SEE ALSO

* [julieta handoff](../handoff.md) - the handoff commands

### Side effects

- **P** (preflight): no
- Lock: no
- Appends on each run: a handoff file
- Writes a julieta snapshot: no
- Idempotency: each run adds one thing

### Exit codes

| Exit | Meaning |
|---|---|
| 0 | ok |
| 1 | the operation failed |
| 2 | usage or precondition |
| 3 | approval required |
| 4 | drift detected, or an interrupted promotion abandoned |
| 5 | refused to protect data |
| 6 | the check ran and found what it checks for |
| 130 | ended by SIGINT |
| 143 | ended by SIGTERM |

A signal wins over a failure the command had already found (1 to 6); a command that had finished its work keeps 0.
