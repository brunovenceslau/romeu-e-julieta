# julieta memory add

add a memory entry to the repo's memory dir

```
julieta memory add [flags]
```

### Examples

```
julieta memory add --title 'Flaky test on arm64' --tag project --tag ci
julieta memory add --title 'Signing waits' --body 'Ask the operator.' --tag feedback --json
```

### Options

```
      --body string       the entry's markdown body
  -h, --help              help for add
      --json              print one JSON document
      --repo string       the repo dir to file under, instead of the repo of the working directory
      --status string     open or done (default "open")
      --tag stringArray   a tag of the entry; repeat for more; exactly one is a type tag: user, feedback, project, reference, handoff
      --title string      the entry's title, one line
```

### Side effects

- **P** (preflight): no
- Lock: no
- Appends on each run: a memory entry
- Writes a julieta snapshot: no
- Idempotency: each run adds one thing

### Exit codes

| Exit | Meaning |
|---|---|
| 0 | ok |
| 1 | the operation failed |
| 2 | usage or precondition |
| 3 | approval required |
| 4 | drift detected, or an interrupted promotion abandoned |
| 5 | refused to protect data |
| 6 | the check ran and found what it checks for |
| 130 | ended by SIGINT |
| 143 | ended by SIGTERM |

A signal wins over a failure the command had already found (1 to 6); a command that had finished its work keeps 0.
