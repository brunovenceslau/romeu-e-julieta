# julieta memory list

list the memory entries of the repo, one index line each, newest first

```
julieta memory list [flags]
```

### Examples

```
julieta memory list
julieta memory list --tag feedback --since 2026-10-28 --limit 20
julieta memory list --query arm64 --status open --json
```

### Options

```
  -h, --help              help for list
      --json              print one JSON document
      --limit int         list at most this many entries
      --query string      list the entries whose title, body or a tag holds this text, ignoring case
      --repo string       the repo dir to file under, instead of the repo of the working directory
      --since string      list the entries updated at or after this RFC 3339 date or timestamp; a date is midnight UTC
      --sort string       order newest first by updated or by created (default "updated")
      --status string     list the entries of this status only: open or done
      --tag stringArray   list the entries that carry this tag; repeat for more, and every one must hold
```

### Side effects

- **P** (preflight): no
- Lock: no
- Appends on each run: nothing
- Writes a julieta snapshot: no
- Idempotency: the command writes nothing

### Exit codes

| Exit | Meaning |
|---|---|
| 0 | ok |
| 1 | the operation failed |
| 2 | usage or precondition |
| 3 | approval required |
| 4 | drift detected, or an interrupted promotion abandoned |
| 5 | refused to protect data |
| 6 | the check ran and found what it checks for |
| 130 | ended by SIGINT |
| 143 | ended by SIGTERM |

A signal wins over a failure the command had already found (1 to 6); a command that had finished its work keeps 0.
