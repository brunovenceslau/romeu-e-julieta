# julieta memory edit

change a memory entry; --status done closes it

```
julieta memory edit <id> [flags]
```

### Examples

```
julieta memory edit 01j9z3k8m6t2q4w5e7r9y1v3k5 --status done
julieta memory edit 01j9z3k8m6t2q4w5e7r9y1v3k5 --title 'Flaky test on arm64 runners' --json
```

### Options

```
      --body string       the new body
  -h, --help              help for edit
      --json              print one JSON document
      --repo string       the repo dir to file under, instead of the repo of the working directory
      --status string     open or done; done closes the entry
      --tag stringArray   a tag; the tags given replace the entry's
      --title string      the new title
```

### Side effects

- **P** (preflight): no
- Lock: no
- Appends on each run: nothing
- Writes a julieta snapshot: no
- Idempotency: a second run with no input change leaves files and refs as they were

### Exit codes

| Exit | Meaning |
|---|---|
| 0 | ok |
| 1 | the operation failed |
| 2 | usage or precondition |
| 3 | approval required |
| 4 | drift detected, or an interrupted promotion abandoned |
| 5 | refused to protect data |
| 6 | the check ran and found what it checks for |
| 130 | ended by SIGINT |
| 143 | ended by SIGTERM |

A signal wins over a failure the command had already found (1 to 6); a command that had finished its work keeps 0.
