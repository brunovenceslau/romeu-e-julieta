# julieta memory show

print one memory entry

```
julieta memory show <id> [flags]
```

### Examples

```
julieta memory show 01j9z3k8m6t2q4w5e7r9y1v3k5
julieta memory show 01j9z3k8m6t2q4w5e7r9y1v3k5 --json
```

### Options

```
  -h, --help          help for show
      --json          print one JSON document
      --repo string   the repo dir to file under, instead of the repo of the working directory
```

### SEE ALSO

* [julieta memory](../memory.md) - the memory commands

### Side effects

- **P** (preflight): no
- Lock: no
- Appends on each run: nothing
- Writes a julieta snapshot: no
- Idempotency: the command writes nothing

### Exit codes

| Exit | Meaning |
|---|---|
| 0 | ok |
| 1 | the operation failed |
| 2 | usage or precondition |
| 3 | approval required |
| 4 | drift detected, or an interrupted promotion abandoned |
| 5 | refused to protect data |
| 6 | the check ran and found what it checks for |
| 130 | ended by SIGINT |
| 143 | ended by SIGTERM |

A signal wins over a failure the command had already found (1 to 6); a command that had finished its work keeps 0.
