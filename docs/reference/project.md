# Project spec

The format `project.v1` of `projects/<name>.yaml` in a config repo, one project per file
([03 3.2](../spec/03-formats.md#32-project-spec-projectsnameyaml-schema-projectv1)).
Gate and Apply are the struct tags of a top-level field (01 1.4): a field whose gate is
widening is in the widening set that gate 2 asks for, and apply says when a change takes
effect, at the next create of the sandbox or on the running one. A member has the class
of its top-level field.

Its JSON Schema is [schemas/project.v1.json](../../schemas/project.v1.json).
