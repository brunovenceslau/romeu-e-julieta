# Checks

Each check of tools/ci registers itself from one file,
`tools/ci/check_<check>.go`, and lives in one package below
`tools/ci/internal/`
([12 12.2](../spec/12-engineering.md#122-development-commands-and-capability-map)).
fast and all run the checks they hold in the order below, except that
every check that judges the tree runs before the first one that runs
code of the change, and the checks of the commit judge the commit read
before any step.
Job is the job of the hosted workflow the check runs in, and `tools/ci <job>` runs the checks of that job alone: `static` judges the commit and the tree and runs none of the tests, `race` is the one test run with the race detector and the coverage check after it, and `e2e` is the container e2e. `tools/ci all` runs the union of the three jobs; `-` marks a check that runs in no job.
The requirement id is the one of the row of the check in the step table of
[10 10.2](../spec/10-testing-style.md#102-ci); `-` marks a row that holds none.
