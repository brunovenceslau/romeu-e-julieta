# romeu init

write the host settings and clone the config repo

```
romeu init --config-url <url> [flags]
```

### Examples

```
romeu init --config-url https://github.com/<owner>/<config-repo>
romeu init --config-url https://github.com/<owner>/<config-repo> --root /abs/dev
romeu init --config-url https://github.com/<owner>/<config-repo> --git-credential-helper osxkeychain
```

### Options

```
      --config-project string          the config project's name (default: the repo's name)
      --config-ref string              the branch that holds projects/<name>.yaml (default "main")
      --config-url string              the https URL of the config repo (required)
      --git-credential-helper string   the git credential helper of a private config repo, for its host only: a git-credential-<name> helper's name, or the absolute path of an executable only you or root can write; recorded as tools.gitCredentialHelper. Git may send it erase when the origin refuses a credential, which deletes what a storing helper (osxkeychain, store) holds
  -h, --help                           help for init
      --root string                    the absolute root of the host tree (default: $HOME/dev)
```

### Side effects

- **P** (preflight): no
- Lock: yes, the romeu lock, for the whole command
- Appends on each run: nothing
- Writes a julieta snapshot: no
- Idempotency: a second run with no input change leaves files and refs as they were

### Exit codes

| Exit | Meaning |
|---|---|
| 0 | ok |
| 1 | the operation failed |
| 2 | usage or precondition |
| 3 | approval required |
| 4 | drift detected, or an interrupted promotion abandoned |
| 5 | refused to protect data |
| 6 | the check ran and found what it checks for |
| 130 | ended by SIGINT |
| 143 | ended by SIGTERM |

A signal wins over a failure the command had already found (1 to 6); a command that had finished its work keeps 0.
