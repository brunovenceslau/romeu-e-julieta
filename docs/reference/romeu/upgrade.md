# romeu upgrade

install a published release of romeu after showing what changed (gate 1)

```
romeu upgrade [--version <tag>] [--check] [flags]
```

### Examples

```
romeu upgrade
romeu upgrade --check
romeu upgrade --version v1.0.0
```

### Options

```
      --check            print the running and the picked versions and change nothing
  -h, --help             help for upgrade
      --version string   install the release of this tag instead of the newest
```

### SEE ALSO

* [romeu](../romeu.md) - the commands that run on the host

### Side effects

- **P** (preflight): yes, the command runs the preflight before its sbx calls
- Lock: yes, the romeu lock, for the whole command
- Appends on each run: nothing
- Writes a julieta snapshot: no
- Idempotency: a second run with no input change leaves files and refs as they were

### Exit codes

| Exit | Meaning |
|---|---|
| 0 | ok |
| 1 | the operation failed |
| 2 | usage or precondition |
| 3 | approval required |
| 4 | drift detected, or an interrupted promotion abandoned |
| 5 | refused to protect data |
| 6 | the check ran and found what it checks for |
| 130 | ended by SIGINT |
| 143 | ended by SIGTERM |

A signal wins over a failure the command had already found (1 to 6); a command that had finished its work keeps 0.
