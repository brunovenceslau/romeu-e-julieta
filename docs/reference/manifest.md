# julieta manifest

The format `manifest.v1`, which romeu passes to julieta on every `sbx env exec` and julieta
caches ([03 3.6](../spec/03-formats.md#36-julieta-manifest-schema-manifestv1)). The rules
that are design decisions, the protocol window and the must-understand rule among them,
are in 03 3.6.

Its JSON Schema is [schemas/manifest.v1.json](../../schemas/manifest.v1.json).
