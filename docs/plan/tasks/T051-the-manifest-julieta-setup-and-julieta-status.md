# T051 - The manifest, `julieta setup` and `julieta status`

Goal: The manifest package, `julieta setup` and `julieta status`;
`tools/schemagen` and `tools/ci schema`, with the manifest as their
first type.

Re-plan (2026-10-12): Kept, changed. `internal/manifest` decodes the
manifest of 03 3.6 with the N and N-1 window and the cache file, against
`schemas/manifest.v1.json`. `setup` links the binary on `PATH`, installs
the global `core.hooksPath` to the dispatcher directory, fast-forwards
clean default branches and runs `memory check`, whose file lands with
T035. `install` and `skills-stale` join with T053 and T079. A
hand-written manifest validates like a rendered one (see
`docs/notes/julieta-by-hand.md`). The `contracts` forecast holds only if
`versions.go` changes. The schema generator and its check land here
with their first input (gap 15 in `docs/plan.md`): `tools/schemagen`
writes `schemas/<format>.v1.json` and the reference page of a format
from its Go type (12 12.3, S10), `tools/ci schema` validates the
examples of each format against its schema with the JSON Schema
validator of 12 12.1, which enters `go.mod` here (rule 7), and T035,
T059 and T021 add their types. The generated schema and page are
generated outputs (rule 1), owned by no task.
