# T008 - The CLI contract: exit codes, error ids per package and registration by file

Earlier title: The CLI contract: the error table, exit codes and the
dispatcher.

Goal: The CLI contract: exit codes, the error ids of 04 4.4 declared per
package with the union test, the text and `--json` forms, command
registration by `init`, and the generated reference pages. `owns` names
the files of `internal/cli` by name, since `internal/cli/writer.go` is
T007's and `internal/cli/errorids_exempt.yaml` is T073's; a file of the
package this list does not foresee is added to it in this task's pull
request.

Re-plan (2026-10-12): Kept, changed. Each package declares its ids in
its own `errors.go`, taken from 04 4.4; one test collects the union.
Commands register by `init` from `internal/cmd/<binary>/<command>/`,
each linked in by its own
`internal/cmd/<binary>/all/import_<command>.go`; the dispatcher has no
hand-kept list, and the `command` and `error` kinds of `tools/new` that
write those files are T009's. The generated pages
`docs/reference/errors.md` and `docs/reference/exit-codes.md` are
regenerated by every task that declares ids (rule 1 of `docs/plan.md`).
`internal/cli/writer.go` belongs to T007, which this task needs. This
task needs T007 only, so it no longer waits for M0's tooling: one link
off every chain through it.

- Acceptance:
  - Lands before its module's place in the order of 12 12.2 (Q26):
    `spec`, `state` and `gitsafe` return its error ids (03, opening; 01
    1.6; 10 10.6), and it needs nothing from the modules between.
  - `internal/cli` exports `Command` (name, usage, the flag binder, the
    side-effect fields of 12 12.3 with no default, and `Run(ctx
    context.Context, env *Env, args []string) error`), `Env` (the
    escaping writers for stdout and stderr, the clock, the ULID source,
    the version stamp, the settings path and the subprocess runners the
    command needs) and `Register(Command)`, called from a package-level
    `var _ = cli.Register(def)` in each command package; `cli.Main(args,
    env)` dispatches and maps the error id to the exit code; a fixture
    command in the package's tests registers and runs through `Main`
    with a fixed clock. The field list is this task's to settle (rule 6
    of `docs/plan.md`).
  - A definition is registered through one constructor whose arguments
    are the five side-effect fields; a fixture definition that leaves
    one unset fails `go test ./internal/cli/...`. A duplicate command
    name panics at `init`, and a test asserts the registry's order and
    names. The lock field of each definition is checked against the list
    of 04 4.1 Locking by a table over the definitions.
  - The two `internal/cmd/<binary>/all/doc.go` files name the package's
    one purpose: the assembled command set each binary's `main.go`
    imports once.
  - An error has an id `RJ-<nnn>`, one sequence that carries no meaning,
    a slug, an exit code, a message and a fix hint, declared in the
    `errors.go` of the package that returns it, with the ids of 04 4.4;
    the text and `--json` forms match 04 4.1, and a `--json` error
    carries `details`, the object the text form prints after the first
    line; tests assert ids, not message text.
  - The id of an error is that of the outermost `*cli.Error` found by
    `errors.As`; a wrapper keeps the inner id (`%w`, no `cli.Error` of
    its own); a test asserts an id through the one helper of
    `internal/cli`'s test-support package, and the meta-test over the
    module's `_test.go` files is T073's. An error chain with no
    `*cli.Error` exits 1 as the error `internal` (`RJ-348`), and a test
    holds that path (item 17 of Decisions of the re-plan in
    `docs/plan.md`, decided on 2026-10-12, as 04 4.4 and 10 10.1 state
    it).
  - The union test reads the rows of 04 4.4 while it holds rows, then
    the source table of `docs/reference/errors.md`, and fails on a
    duplicate id, an id not in 04 4.4, a row marked retired that a
    package declares, and an id whose slug or exit code differs from its
    row; an id of 04 4.4 that no package declares is listed by `go test
    -run TestErrorIDsPending -v` and fails only from T073. A row marked
    retired is skipped by the union test and kept in the table with its
    last text. `check-findings` maps to exit 6 and is the only id that
    does.
  - A warning is a row of the table by slug with no id; a test fails a
    slug printed by the CLI writer as a warning that is no row.
  - The fix hint of `RJ-338` is the one fixed text that 04 4.4 quotes,
    and a test fails when the table's hint differs from it by a byte;
    the reference is that row's quoted text, read from the page by the
    test with its code-span backticks stripped, so the table's hint
    holds no backtick (round 17, R17-06; round 18, R18-A7). A test fails
    a fix hint that starts with neither a command line nor `decide:`,
    except that one hint. A table test fails a hint that names
    `--overwrite-drift`, `--accept-loss` or `--force` without a clause
    on what the flag discards.
  - A test reads every registered command definition and fails a fix
    hint (other than `RJ-338`'s) or a `--help` example whose command,
    subcommand or flag the definitions do not have; it runs on every
    pull request, so each command task is checked when it registers.
  - Each id has a recovered-in cell, a `docs/guide/` anchor or `none:
    <reason>`; a test fails an id without one, and `errors.md` links it.
  - `go generate` writes the three consumers of the table (12 12.3): the
    exit-code sections of `--help`, `docs/reference/errors.md` and
    `docs/reference/exit-codes.md`, the pages with the generated-file
    header and front matter; the exit-code section of `--help` and
    `docs/reference/exit-codes.md` list 130 and 143 with the precedence
    sentence of 04 4.1 Signals.
