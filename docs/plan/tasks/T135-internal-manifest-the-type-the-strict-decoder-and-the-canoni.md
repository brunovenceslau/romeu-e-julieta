# T135 - `internal/manifest`: the type, the strict decoder and the canonical encoder

Goal: The romeu-julieta contract type of 03 3.6 as its own task, so
every M1 package that reads the manifest (`memory`, `hooks`, `handoff`,
`snapshot`) waits for the type and not for `setup` and `status`: the Go
type, the strict decoder (`encoding/json/v2`, unknown members rejected,
03 opening) with the N and N-1 protocol window, the canonical encoder
over `canon`, the 32 KiB size rule as one function that `sync` (T043)
and `spec validate` (T055) call, and the first schema under `schemas/`,
generated by `tools/schemagen` (T125). With the first file under
`schemas/`, `LICENSES/CC0-1.0.txt` and the `REUSE.toml` entries for
`schemas/` and `examples/` land here, moved from T051.
`internal/manifest/versions.go` is on the `contracts` surface.

Re-plan (2026-10-12, stage B): New, split from T051, so T035, T043,
T054, T059 and T060 need the type and not the two commands.

- Implements: REQ-0215 (03 3.6), REQ-0217 (03 3.6), REQ-0218 (03 3.6),
  REQ-0219 (03 3.6), REQ-0220 (03 3.6), REQ-0224 (03 3.6).
- Operator: no
- Acceptance:
  - A manifest whose `protocol` is outside the window N, N-1 is refused
    with `manifest-protocol` (`RJ-342`, exit 2), with a table over N-2,
    N-1, N and N+1; a newer `schema` version is `format-newer`
    (`RJ-311`).
  - A document with a duplicate member name and one with an unknown
    member are each refused (10 10.6, the decoder list), one fixture
    each.
  - The encoder writes canonical JSON (`canon`) and a round trip of the
    32 KiB fixture of I30 is byte-identical; the size function reports
    the encoded size `sync` and `spec validate` compare with the cap of
    03 3.6.
  - `schemas/manifest.v1.json` is generated and `tools/ci schema`
    passes; `reuse lint` passes with the two CC0-1.0 entries.
- Verify: `go test ./internal/manifest/...`; `go run ./tools/ci schema`
  exits 0.
