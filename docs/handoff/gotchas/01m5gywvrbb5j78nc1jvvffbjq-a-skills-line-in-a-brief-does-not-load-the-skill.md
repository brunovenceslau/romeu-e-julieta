# A SKILLS line in a brief does not load the skill

The brief guard accepts a `SKILLS:` line, and a subagent reads it as a
label: 25 briefs, 1 Skill call (2026-10-21 and 2026-10-22).

Write the instruction ("call the Skill tool for X now; for Y before your
first edit in the domain") and measure the Skill calls in the
subagent's transcript, not its report.
