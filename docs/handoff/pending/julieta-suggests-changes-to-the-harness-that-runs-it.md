# julieta suggests changes to the harness that runs it

An idea, recorded on 2026-10-17 so it is not lost; nothing is designed
or planned yet. julieta would have a command, and a specialized skill,
that suggest changes to the harness that runs it: the configuration
project of the instance (verona, in the author's own), its
kits and its agent setup. Neither the command nor the skill exists in
the specification or the plan, and no task holds it.

Cost now: none beyond this note. Before any work, it needs the scope
(what julieta reads to make a suggestion, and whether it only proposes
or also opens a change) and a place in the plan.

Reopen: the re-plan after M1, or the first task that adds a julieta
command beyond the daily ones.
