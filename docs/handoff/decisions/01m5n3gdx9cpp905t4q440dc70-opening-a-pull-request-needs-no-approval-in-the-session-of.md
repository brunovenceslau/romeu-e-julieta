# Opening a pull request needs no approval in the session of 2026-10-23

What is at stake: low. A pull request opened without the question breaks
no rule in this session, and it can be closed; a branch pushed to open it
can be deleted.

Decided on 2026-10-23. Scope: this session only, in this repository; the
rule of "Pushes and pull requests are asked first from 2026-10-22"
(01m5gywvgc85vj8k4txzppjz6d) stands for every other session, and this
note does not replace it.

Opening a pull request needs no approval in this session, and a push of
a branch to open it is included. This narrows that record: a body edit
that triggers CI, a comment, a push to a branch with no pull request to
open, and a push to a branch that already has one are still asked first.
