# Pushes and pull requests are asked first from 2026-10-22

What is at stake: low. A push or a pull request made without asking
breaks the rule, and the branch can be deleted; a wrongly asked one
costs a question.

Decided on 2026-10-22. Scope: this repository, every session until it
is changed.

Every push and every pull request (open, a body edit that triggers CI,
a comment) is asked first, each time. This narrows "Work authorized
while the operator is away on 2026-10-21" (01m5eg0qefcvwdx05q4vnqcwfe),
whose other points stand. A branch pushed with no pull request to keep
work on the remote is asked first too.
